# 桌面端本地页面

这些页面打包进应用，**不加载任何远程资源**（CSP 限制 + 必须离线可用）。

| 文件 | 用途 |
|---|---|
| `settings.html` / `.css` / `.js` | 连接设置窗口（`⌘,` 或菜单打开） |
| `handoff.html` | 早期表单交接跳板页，现已改为 GET 导航，保留作参考 |
| `error.html` / `error.css` | 交接失败时的本地错误页，替代邮箱登录页 |
| `index.html` | 窗口初始占位页 |

## 设计约束

样式遵循 kiln，但**两个页面属于不同的层**，判据是"这个表面上有没有要反复做的工作"：

| 页面 | 层 | 依据 |
|---|---|---|
| `settings.*` | 工作台（`tokens/index.css`） | 有表单要反复填、有状态要反复看 |
| `error.*` | 纸面（`tokens/paper.css`） | 一句事实、一个出口，没有重复工作 |

两层共用同一套釉色 palette、单锚点规则和反装饰清单；纸面反转的是密度、材质和
字号天花板。**不要把工作台的紧凑密度搬到错误页**（13px 正文、36px 控件、贴边排布），
那会得到一张"缩水的工作台"——所有失败版本里最难看的一种，而且它每次都是一点一点
滑过去的，没有任何一次改动看起来像是错的。

因为不能引用远程资源，token 在各自 CSS 的 `:root` 内联声明，**值与 kiln
`references/tokens.md` + `tokens/paper.css` 逐条对应**。

修改时以 token 表为准，不要就地调数值。上一版是照印象手写近似值——标题 30px、
卡片圆角 14px、底色偏黄、阴影自拟——每处都差一点，叠起来内容撑破了 640×720 的
窗口，用户看到的是滚动后被截断的半行标题。

几条容易踩的：

- **页面标题不得超过 16px**。admin 界面里 30px 标题是 hero type，kiln 明列为
  anti-pattern。
- **圆角是精确的 4 / 6 / 8 阶梯**：控件 4px、卡片 6px、大面板 8px。不要用倍数派生。
- **阴影必须是暖黑** `rgba(54,47,42,·)`，不是冷灰。白卡无边框，靠留白与阴影浮在
  近白画布上；边框只用于输入框等真正需要的地方。
- **陶土红只给「本流程唯一的关键动作」**。连接设置窗口里就是「测试连接并保存」，
  错误页里就是「打开连接设置」，全视口仅此一个红色填充。普通提交用墨黑。
- **纸面页禁用一切柔光阴影**（纸不浮在纸上面），分层只能靠颗粒与印刷细线；焦点环
  因此用 `outline` 而不是 `box-shadow`。错误页旧版正是一张带 `0 14px 44px` 投影、
  16px 圆角的白卡，加一整块琥珀色原因填充——那块填充还和标题争"先看哪个"，并造出
  第二个高饱和信号。
- **主窗口在 macOS 上是 overlay 标题栏**（`hidden_title`），本地页面必须自带
  `data-tauri-drag-region` 拖拽带，否则窗口拖不动，交通灯还会压在内容上。
- **密码类字段必须有显示/隐藏切换**。
- 过渡 120–200ms，只作用于颜色、背景、边框、阴影。不缩放、不弹跳、不做装饰性动画，
  并尊重 `prefers-reduced-motion`。

## 文案

- 一个动作在整个流程里保持同名：按钮「测试连接并保存」→ 进行中「正在连接…」→
  成功「已保存」。
- 错误说明发生了什么以及能怎么办，不要用「保存失败」把 Rust 侧已经写清楚的具体
  原因盖掉。
- 不写只描述实现或复述可见控件的填充文字。
