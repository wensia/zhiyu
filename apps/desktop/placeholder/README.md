# 桌面端本地页面

这些页面打包进应用，**不加载任何远程资源**（CSP 限制 + 必须离线可用）。

| 文件 | 用途 |
|---|---|
| `settings.html` / `.css` / `.js` | 连接设置窗口（`⌘,` 或菜单打开） |
| `handoff.html` | 早期表单交接跳板页，现已改为 GET 导航，保留作参考 |
| `error.html` / `error.css` | 交接失败时的本地错误页，替代邮箱登录页 |
| `index.html` | 窗口初始占位页 |

## 设计约束

样式遵循 kiln 工作台设计语言。因为不能引用远程资源，token 在 `settings.css`
的 `:root` 内联声明，**值与 kiln `references/tokens.md` 逐条对应**。

修改时以 token 表为准，不要就地调数值。上一版是照印象手写近似值——标题 30px、
卡片圆角 14px、底色偏黄、阴影自拟——每处都差一点，叠起来内容撑破了 640×720 的
窗口，用户看到的是滚动后被截断的半行标题。

几条容易踩的：

- **页面标题不得超过 16px**。admin 界面里 30px 标题是 hero type，kiln 明列为
  anti-pattern。
- **圆角是精确的 4 / 6 / 8 阶梯**：控件 4px、卡片 6px、大面板 8px。不要用倍数派生。
- **阴影必须是暖黑** `rgba(54,47,42,·)`，不是冷灰。白卡无边框，靠留白与阴影浮在
  近白画布上；边框只用于输入框等真正需要的地方。
- **陶土红只给「本流程唯一的关键动作」**。连接设置窗口里就是「测试连接并保存」，
  全视口仅此一个红色填充。普通提交用墨黑。
- **密码类字段必须有显示/隐藏切换**。
- 过渡 120–200ms，只作用于颜色、背景、边框、阴影。不缩放、不弹跳、不做装饰性动画，
  并尊重 `prefers-reduced-motion`。

## 文案

- 一个动作在整个流程里保持同名：按钮「测试连接并保存」→ 进行中「正在连接…」→
  成功「已保存」。
- 错误说明发生了什么以及能怎么办，不要用「保存失败」把 Rust 侧已经写清楚的具体
  原因盖掉。
- 不写只描述实现或复述可见控件的填充文字。
